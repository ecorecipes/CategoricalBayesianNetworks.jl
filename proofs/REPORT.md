## 2. Exact mathematical objects and premises

An arbitrary `Signature S` consists of:

```lean
Ty : Type
Label : Type
inputs : Label → List Ty
result : Label → Ty
```

Neither types nor labels are required to be finite. Every mechanism has a finite,
ordered input profile and one output. An `Interface S` has a finite carrier
`Port : Type` and a map `type : Port → S.Ty`.

A `Net X Y` has:

* a finite generator set `G`;
* `label : G → S.Label`;
* `parents : G → List (X.Port ⊕ G)`;
* an **arbitrary** `output : Y.Port → X.Port ⊕ G`;
* equality of each parent list's mapped types with `S.inputs (label g)`;
* output-leg type preservation;
* `∃ rank : G → ℕ, ∀ g h, inr h ∈ parents g → rank h < rank g`.

The canonical variable set is `X.Port ⊕ G`. Its input map is `inl`, and its
generator-target map is `inr`. Thus the input map is injective and identifies
exactly the exogenous variables; every other variable has exactly one generator.
No output injectivity, input/output disjointness, output reachability,
nonemptiness, distinct-parent condition, kernel normalization, or name-uniqueness
premise is present.

A rank is a proof of existence, not stored observable syntax. In particular,
different rankings do not produce different arrows. `Net.no_directed_cycle`
proves that the dependency relation's transitive closure is irreflexive.

An `Iso f g` consists only of a generator bijection `e` satisfying:

```text
g.label (e a) = f.label a
g.parents (e a) = map (Sum.map id e) (f.parents a)
g.output y = Sum.map id e (f.output y)
```

The quotient relation is `Nonempty (Iso f g)`. Its equivalence laws are proved
using identity, inverse, and composite bijections. `ofNet_eq_iff` proves that
quotient equality is exactly this relation.

### Attribute coverage

`Ty` may be a record containing a variable name, its ordered state-name table,
and `space_ref`. `Label` may include mechanism name, kernel reference, target
attributes, and the ordered input-attribute profile. The signature then returns
those profiles. This permits the same mechanism reference with different
profiles by using different full labels. Structural isomorphisms preserve the
chosen values; they only renumber parts. No global unique-name policy is built
into the mathematics.

This is a general attribute-parametric encoding, not a verified conversion from
Julia's `State`, `Input`, `KernelRef`, or ACSet implementation.

## 3. Actual operations and derived closure

For `f : Net X Y` and `g : Net Y Z`, composition has generator set
`Gf ⊕ Gg` and variable set `X.Port ⊕ (Gf ⊕ Gg)`. Its two variable maps are:

```text
left  (inl x) = inl x
left  (inr a) = inr (inl a)
right (inl y) = left (f.output y)
right (inr b) = inr (inr b)
```

First-component parent lists are mapped by `left`; second-component parent
lists by `right`; the final output is `right ∘ g.output`. This is a total
definition for matching typed feet, not an existence certificate or a solver
correctness field.

`compose_acyclic` derives closure from the two operand ranks. If `rf` and `rg`
are witnesses, choose
`bound = sup {rf a | a ∈ Gf} + 1`, and use ranks `rf a` and `bound + rg b`.
The proof checks original left edges, substituted right input occurrences,
and original right internal edges separately. It never assumes acyclicity of
the composite.

Tensor uses disjoint sums of the two input sets, two generator sets, and two
output sets. Both parent lists and outputs are mapped by their corresponding
sum embeddings. `tensor_acyclic` uses the original rank on each summand because
there are no cross-component edges.

`Iso.comp` and `Iso.tensor` prove well-definedness of both operations on the
structural quotient.

## 4. Category, symmetric monoidal, and copy-discard theorems

All statements in this section are universally quantified over the arbitrary
signature and all well-typed network arrows. Their only network premises are
the data and validity conditions listed in §2.

| Headline declaration | Exact scope and proof idea |
|---|---|
| `Net.id_comp_iso`, `Net.comp_id_iso` | Structural identity laws via empty-sum generator bijections. |
| `Net.assoc_iso` | Structural associativity for every composable triple, via `Equiv.sumAssoc`; parent lists and substituted outputs are checked, including pass-through cases. |
| `category` | Actual Mathlib `Category (Interface S)` with the above quotient, identity, and composition. |
| `Net.interchange_iso`, `tensor_comp` | `(f ⊗ g);(h ⊗ k) = (f;h) ⊗ (g;k)`, proved by exchanging the middle two generator summands. |
| `wire_comp`, `wire_tensor` | Pure boundary maps compose contravariantly and tensor by disjoint union. Pure wiring has no generators. |
| `Net.slide`, `wire_slide` | A general incidence-preserving sliding lemma; its hypotheses are label/parent/output equations, not category equations. |
| `assoc_natural`, `left_natural`, `right_natural`, `swap_natural` | Naturality for arbitrary nonempty syntax, via explicit generator bijections and the sliding lemma. |
| `monoidal` | Actual Mathlib `MonoidalCategory`: tensor identities/interchange, associator/unitors, naturality, pentagon, and triangle. |
| `symmetric` | Actual Mathlib `SymmetricCategory`: natural braiding, both hexagons, and symmetry squared equal to identity. |
| `comonoid`, `commComonoid` | Every foot has counit, coassociative comultiplication, both counit laws, and commutativity. |
| `copyDiscard` | Actual Mathlib `CopyDiscardCategory`: additionally coherent copy/discard on tensor and on the empty unit. |

Associators, unitors, and symmetry are bijective wiring on ports. Pentagon,
triangle, both hexagons, and involutivity reduce to equality of their actual
port functions, proved by cases on the finite-sum constructors.

Copy is the port codiagonal read contravariantly:
`wire (Sum.elim id id) : X → X ⊗ X`. Discard is
`wire Empty.elim : X → I`. These definitions preserve hidden syntax when
postcomposed with a mechanism-bearing arrow.

**No Markov-category instance is asserted.** Naturality of discard is false
for these structural-isomorphism classes; §7 gives a formal counterexample.

## 5. Equivalence with general legged finite networks

`Legged X Y` has independent arbitrary finite sets of variables and generators,
a variable-type map, mechanism labels, ordered parent lists, injective targets,
an injective input leg, and an unrestricted output leg. Its two additional
partition conditions are:

```text
∀ x g, input x ≠ target g
∀ v, (∃ x, input x = v) ∨ (∃ g, target g = v).
```

Input, output, target, and parent typing are explicit. A variable ranking
strictly increases along every parent-to-target incidence.

`partition_bijective` proves that `Sum.elim input target` is a bijection from
inputs plus generators to the original variables. `normalise` transports
ordered parents and the arbitrary output leg along its inverse, retaining all
generators. Its acyclicity follows from the original ranking.

The converse `Net.toLegged` is explicit, with `inl`/`inr` legs and variable rank
zero on inputs and `rank g + 1` on generated variables. Its validity is proved.
The main representation results are:

```text
Net.normalise_roundtrip f :
  Net.Iso f.toLegged.normalise f

Legged.representation_iso N :
  Legged.Iso N.normalise.toLegged N

Legged.representation_faithful N M :
  ofNet N.normalise = ofNet M.normalise ↔
  Nonempty (Legged.Iso N M).
```

`Legged.Iso` has independent variable and generator bijections preserving
types, labels, both legs, targets, and ordered parent lists.
`normalise_respects_iso` and `Net.Iso.toLegged` establish compatibility with
structural renumbering. Thus the canonical category does not discard distinctions
present in the general legged presentation.

## 6. Pushout/gluing relationship

`variable_pushout` proves the complete universal property of the composite
variable set. For every target type `T` and maps `u : f.Var → T`,
`v : g.Var → T` with

```text
∀ y, u (f.output y) = v (inl y),
```

there exists a **unique** mediator `m` satisfying
`m ∘ left = u` and `m ∘ right = v`. No injectivity of `f.output` is assumed.
`gluing_commutes` gives the commuting square.

`gluing_parents`, `gluing_targets`, and `gluing_labels` prove the exact
transport equations. `ApexMap` then packages arbitrary apex maps preserving
types, labels, generator targets, and complete ordered parent lists.
`apex_pushout` proves a unique mediator for **all** compatible apex maps into
any other typed network apex. The generator mediator is `Sum.elim`; the
variable mediator is the one from `variable_pushout`.

This is a structural attributed ordered-incidence pushout universal property,
not merely a variable-cardinality calculation. The general legged
representation theorem transports its meaning to arbitrary valid leg maps.
It does not claim a kernel-checked correspondence to Catlab's concrete
colimit code or its state-part implementation.

## 7. Nonvacuity and retained hidden structure

`Examples.mixed` has:

* one input;
* a visible mechanism whose two ordered parents are the same input;
* a separate hidden nullary mechanism;
* three output occurrences: the input itself, the visible generated variable,
  and another copy of that same generated variable.

Proved facts:

```text
copied_outputs        : ¬ Function.Injective mixed.output
pass_through          : mixed.output 0 = inl ()
hidden_component      : ∀ y, mixed.output y ≠ inr true
repeated_slots        : mixed.parents false = [inl (), inl ()]
copied_substitution   : (mixed.comp consumer).parents (inr ()) =
                        [inr (inl false), inr (inl false), inl ()]
hidden_survives       : generatorCount (mixed;consumer) = 3.
```

`mixed_associativity`, `mixed_identity`, and `mixed_tensor_interchange`
instantiate the category laws on these actual mechanisms and repeated/copied
occurrences, rather than just on empty diagrams.

Generator count is well-defined on the quotient and additive for composition
and tensor. It yields:

```text
discard_not_natural :
  ofNet mixed ≫ discard three ≠ discard one
```

because the left side has two generators and the right side has none.
`hiddenScalar` is a one-generator nullary network with **both feet empty**.
`hidden_scalar_not_identity` distinguishes it from the empty identity, and
`hidden_scalar_associativity` exercises three such hidden components.

## 8. Deliberate remaining boundaries

1. **The name-sensitive Julia wrapper is partial.** Its interfaces can match
   and its structural pushout can be valid while `_validate_composite` rejects
   duplicate internal variable or mechanism names. For example, two individually
   uniquely named hidden priors with the same names have matching empty feet;
   their disjoint-union apex retains both names and triggers the unique-name
   policy. This is a source-level consequence of `composition.jl:73–113`, not a
   newly executed Julia regression. The formal category preserves attributes
   without global unique-name constraints and is not claimed to make that
   convenience wrapper total.
2. **No Julia/ACSet refinement theorem.** Numeric part indices, state rows,
   explicit position validation, mutable builders, exception behavior,
   `oapply`, mechanism-replacement `substitute`, and the wrappers' runtime
   name policies are not verified here.
3. **Acyclicity presentation.** The mathematical structures carry existence
   of natural-number rankings, and absence of directed cycles is derived.
   The conversion from Julia's graph validator to such a certificate is not
   formalized. Normalization itself does not require a chosen topological
   order and never retains a rank as observable data.
4. **No numerical semantics functor.** In particular, this does not extend
   the earlier restricted-boundary FinStoch semantics theorem to these general
   boundaries. The new construction is syntax first; no semantic equality
   was used to obtain any category equation.
5. **No DVE claim.** DVE belongs to a separate Lean task and repository scope.
6. **No computational-isomorphism algorithm claim.** The quotient is a
   mathematical quotient; general legged normalization uses classical choice
   to invert a proven bijection.
